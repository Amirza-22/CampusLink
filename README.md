# CampusLink
CampusLink is a campus activity platform designed to help college students discover, create, and join activities while connecting with other students.
## Project Purpose
Our goal is to make it easier for students to find activities on campus, meet new people, and get involved in their college community.
## Main Features
- User registration and login
- Student profiles
- Campus activity feed
- Create and join activities
- Search and filter activities
- Campus maps
- Report activities
